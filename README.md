## Сравнение

Детекция показывает объект прямоугольной рамкой (bounding box) и подписывает класс с уверенностью. Она работает быстро, но не различает точную форму объекта.

Сегментация выделяет объект попиксельно цветной маской, показывая его реальную форму. Это точнее, но медленнее и требует больше ресурсов. Также сегментация YOLOv8 распознаёт меньше классов, чем детекция.


**Вывод:** детекция удобна для быстрого подсчёта объектов и определения их местоположения; сегментация — для задач, где важна точная форма объекта (например, отделение от фона).
