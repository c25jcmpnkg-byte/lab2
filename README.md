## Задание 4. Детекция объектов и семантическая сегментация

### 4.1. Детекция объектов

Все извлечённые кадры из папки `frames/` прогнаны через предобученную модель **YOLOv8n** (`yolov8n.pt`). Для каждого кадра получены:

- **bounding box** — координаты прямоугольной рамки вокруг объекта;
- **класс объекта** (например, `person`, `car`, `dog`);
- **confidence** — уверенность модели в диапазоне от 0 до 1.

### 4.2. Семантическая сегментация

Те же кадры прогнаны через модель **YOLOv8n-seg** (`yolov8n-seg.pt`). Для каждого кадра получены:

- **пиксельные маски** объектов;
- **класс** для каждой маски;
- **confidence** для каждой маски.

### 4.3. Сохранение результатов

Аннотированные кадры сохранены в отдельные директории:

- `output_detection/` — кадры с рамками (детекция)
- `output_segmentation/` — кадры с масками (сегментация)

## Сравнение детекции и сегментации

**Детекция** показывает объект прямоугольной рамкой (bounding box) и подписывает класс с уверенностью. Она работает быстро, но не различает точную форму объекта — рамка всегда прямоугольная, поэтому в неё могут попадать лишние пиксели (фон, части других объектов).

**Сегментация** выделяет объект попиксельно цветной маской, показывая его реальную форму и контуры. Это точнее, но медленнее и требует больше вычислительных ресурсов. Также сегментация YOLOv8 распознаёт меньше классов, чем детекция, и не различает отдельные объекты одного класса (например, двух людей закрашивает одним цветом).

**Вывод:** детекция удобна для быстрого подсчёта объектов и определения их местоположения; сегментация — для задач, где важна точная форма объекта (например, отделение от фона).
